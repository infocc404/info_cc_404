## 📁 هيكلة ملفات المشروع (Project Structure)

```text
├── index.html              # هيكل الصفحات (Home Wireframe 1، الحاويات الديناميكية، شريط التنقل)
├── style.css               # ملف التنسيقات الكامل (نظام الألوان الدافئ + تنسيقات صفحات الأساتذة والرتب)

├── sw.js                   # Service Worker المحدث (info-cc-404-v3) مع دعم الكاش الكامل دون إنترنت
├── manifest.webmanifest    # إعدادات PWA للتثبيت على الهواتف بمسارات نسبية وألوان دافئة
├── planning.pdf            # ملف PDF لجدول التوقيت الأصلي (يرفع في المجلد الرئيسي)
├── icon.svg                # أيقونة المتجهات
├── icon-192.png            # أيقونة PWA 192px
├── icon-512.png            # أيقونة PWA 512px
├── supabase.sql            # مخطط قاعدة البيانات v3 وسياسات RLS ودوال الرتب (my_role, owner_list_users, ...)
└── info-cc-404.zip         # الأرشيف المضغوط الكامل للتحميل المباشر
```

## 🧭 مخطط مسارات الموقع والوايرفريمز (Routes & Features)

1. **الصفحة 1: الرئيسية (`#/`) — Wireframe 1**:
   - وسام `INGÉNIEUR D'ÉTAT EN INFORMATIQUE`
   - العنوان: `كل دروس وتمارين الدفعة، في بلاصة وحدة`
   - بطاقات الإحصائيات الثلاث: 10 أفواج | 7 مواد | عدد الملفات
   - قسم "كيف تستعمل الموقع" مع البطاقات الثلاث وتلميح: *"للوصول للأفواج: اضغط «الأفواج» في الشريط العلوي"*.
   - استمارة الدخول والتسجيل ونافذة استرجاع كلمة السر.

2. **الصفحة 2: الأفواج العشرة (`#/groupes`) — Wireframe 2**:
   - شبكة 10 بطاقات للأفواج (5 في السطر على الحاسوب).
   - تمييز فوج الطالب بشارة `فوجك`.
   - جدول التوقيت الأسبوعي `برنامج الحصص — ING1 السداسي 1 (2026/2027)`.
   - زر `فتح الـ PDF الأصلي` لفتح `planning.pdf`.

3. **الصفحة 3: صفحة الفوج (`#/groupe/N`) — Wireframe 3**:
   - مسار التنقل: `الرئيسية › الأفواج › GN`.
   - بطاقة جدول المواد السبعة الرسمية: `المادة | أستاذ TD (فوجك) | أستاذ TP (فوجك) | الكور (موحد)`.
   - أسماء الأساتذة قابلة للضغط للذهاب مباشرة لصفحة الأستاذ المعني.
   - زر `دروس الكور ←` لكل مادة.
   - قسم `ملفات TD / TP والامتحانات تاع فوجك` مع الفلاتر والبحث.

4. **الصفحة 4: الكور الموحد (`#/groupe/N/cours` و `#/cours`) — Wireframe 4**:
   - شبكة بطاقات المواد السبعة (3 في السطر).
   - عرض أساتذة المحاضرات الرسميين وعدد المحاضرات.
   - عند فتح أي مادة (`#/groupe/N/cours/<subjectId>`): تظهر ملفات الكور حصراً مع زر `فتح`.

5. **الصفحة 5: الأساتذة ومخطط التدريس (`#/profs` و `#/profs/:id`) — Feature A**:
   - قائمة شاملة بأساتذة السداسي المستخرجين مباشرة من الوثيقة الرسمية بدون أي تزييف.
   - بطاقة لكل أستاذ: المواد التي يدرسها، ونوع الحصص (Cours / TD / TP)، والأفواج المعنية.
   - صفحة الأستاذ التفصيلية (`#/profs/:id`): جدول توزيع الحصص والقاعات الكامل + قائمة الملفات التابعة لمقاييس الأستاذ.

6. **الصفحة 6: جميع الملفات (`#/fichiers`)**:
   - البحث الشامل وفلاتر السداسي، المادة، النوع، والفوج.

7. **الصفحة 7: لوحة الإدارة وتفويض الرتب (`#/admin`) — Feature B**:
   - متاحة للمالك (Owner)، المشرفين (Admins)، ورافعي ملفات الأفواج (Uploaders).
   - تبويب رفع الملفات: تحديد المادة والسداسي والنوع والفوج. بالنسبة لرافع ملفات الفوج، يتم تثبيت الفوج تلقائياً على فوجه المفوض.
   - تبويب إدارة الرتب (للمالك حصراً): عرض قائمة المسجلين عبر `owner_list_users()`، وتعيين مندوب لكل فوج كرافع ملفات عبر `owner_set_uploader()`، أو إلغاء التفويض عبر `owner_remove_uploader()`.
   - تبويب إدارة وحذف الملفات المرفوعة.

## 🛠️ إعداد Supabase وتطبيق التحديث (v3)

1. ادخل إلى **Supabase Dashboard** > مشروعك > **SQL Editor** > **New query**.
2. انسخ والصق محتوى ملف `supabase.sql` بالكامل واضغط **Run**.
3. قم بتسجيل حسابك في الموقع، ثم في SQL Editor نفذ:
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'locoviber16@gmail.com'
   on conflict do nothing;
   ```
4. بعد ذلك سيصبح حسابك هو المالك `Owner` وستظهر لك لوحة التحكم الكاملة وإدارة المستخدمين.
